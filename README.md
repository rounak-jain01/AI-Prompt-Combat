# 🏆 AI Prompt Combat

<!-- ![AI Prompt Combat Banner](src/assets/banner.jpg) -->

**"Where Prompting Meets Precision"**

AI Prompt Combat is a high-stakes prompt engineering competition organized by **Kaggle Koders × KalaSarthi**. This modern, award-winning web application serves as the official landing page for the event, featuring immersive animations, a premium dark gold aesthetic, and a seamless user experience.

---

## ✨ Features

### 🎨 **UI/UX Design**
- **Premium Aesthetic:** A "Dark Mode" Gold & Black theme (`#050505`, `#D4AF37`) for a luxurious and tech-centric feel.
- **Glassmorphism:** Heavy use of frosted glass effects on cards, navbars, and overlays.
- **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.
- **Custom Scrollbar:** A themed golden scrollbar replacing the default browser scrollbar.

### 🚀 **Key Sections**
1.  **Hero Section:** - Infinite looping background animation.
    - Glowing "Neon" text effects.
    - 3D Floating elements and particle effects.
2.  **About & Timeline:** - Staggered entrance animations using `Framer Motion`.
    - "Connected Node" timeline for desktop and vertical timeline for mobile.
3.  **Past Events Legacy:** - **Draggable Infinite Carousel:** An interactive, never-ending marquee of past event glimpses.
    - Cinema-style poster cards with zoom-on-hover effects.
4.  **Prizes Podium:** - A 3D-style podium layout for Winners (Gold, Silver, Bronze).
    - Glowing crown animations and metallic gradients.
5.  **Team & Organizers:** - Hierarchical tree structure (Leaders -> Members).
    - Interactive profile cards with gold badge overlays.

---

## 🛠️ Tech Stack

This project is built using the latest modern web technologies for maximum performance and scalability.

- **Framework:** [React.js](https://reactjs.org/) (v18+)
- **Build Tool:** [Vite](https://vitejs.dev/) (Fast HMR)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) (Complex gestures & layout animations)
- **Icons:** [Lucide React](https://lucide.dev/) (Lightweight & Consistent icons)
